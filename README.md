# Tutorial Mod

A simple Minecraft Fabric mod created as a learning project.

The goal of this project is to explore Fabric mod development, understand the modding workflow, and experiment with Minecraft's APIs. It is primarily intended for educational purposes and may be updated as new features and concepts are learned.

## Setup

To set up the development environment, please refer to the official Fabric documentation:

https://docs.fabricmc.net/develop/getting-started/creating-a-project

## Building

To build the mod, run:

```bash
./gradlew build
```

The compiled mod `.jar` file will be generated in the `build/libs` directory.
